Duit Harian di Home Screen

Pasang sebagai aplikasi supaya mudah dibuka seperti app biasa.

iPhone (Safari)
  1. Buka website ini menggunakan Safari.
  2. Tekan butang Share (ikon kotak dengan anak panah).
  3. Pilih Add to Home Screen / Tambah ke Skrin Utama.
  4. Tekan Add / Tambah.
Android (Chrome)
  1. Buka website ini menggunakan Chrome.
  2. Tekan menu tiga titik di penjuru.
  3. Pilih Install app atau Add to Home screen.
  4. Ikut arahan pemasangan.

Nota: pemasangan PWA memerlukan website dihoskan melalui HTTPS (atau localhost).
